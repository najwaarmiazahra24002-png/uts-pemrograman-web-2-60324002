## Deskripsi Aplikasi
Aplikasi ini merupakan sistem CRUD (Create, Read, Update, Delete) sederhana untuk mengelola data kategori buku.  
Fitur utama:
- Menampilkan daftar kategori buku
- Menambah kategori baru
- Mengedit data kategori
- Menghapus kategori
- Validasi data menggunakan PHP 
- Menggunakan prepared statement untuk keamanan database

## Cara Instalasi dan Menjalankan Aplikasi
1. Siapkan Web Server
   Pastikan sudah terinstall:
   - XAMPP 
   - PHP
   - MySQL

2. Pindahkan Project
   Letakkan folder project ke direktori web server:
   - XAMPP: `C:/xampp/htdocs/uts_60324002/`

3. **Jalankan Apache dan MySQL**
   Aktifkan melalui XAMPP 

4. **Buat Database**
   - Buka `http://localhost/phpmyadmin`
   - Buat database baru (contoh: `uts_perpustakaan_60324002`)
